# Lumer Repository-Owned Operating Layer

This directory contains version-controlled policy and bundle templates for the dedicated Hermes profile **Lumer**. Profile-local state (`config.yaml`, `.env`, `SOUL.md`, memories, sessions and runtime state) belongs under the Hermes profile home on Pi5 and must not be committed.

- Canonical policies: `.lumer/policies/`
- Bundle templates: `.lumer/bundle-templates/`
- Project skills: `.hermes/skills/`
- Workflows/context: `.hermes/workflows/`, `.hermes/project-context/`
