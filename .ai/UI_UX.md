# CardeLume UI/UX — Current Step17I Direction

## Brand promise

**Beautiful cards, made in moments.**  
**Make their moment shine.**

The user tells CardeLume the occasion and emotional context; CardeLume does the design.

## Experience

```text
Homepage
→ small brief
→ premium generation/reveal
→ 3 genuinely different directions
→ choose
→ minimal/reversible finishing
→ preview
→ pay once
→ keepsake-ready JPG/PDF + recovery
```

## Visual language

- deep navy;
- warm ivory;
- restrained champagne/gold;
- editorial serif display + clean international UI sans;
- tactile paper depth/materiality;
- subtle light metaphor;
- cinematic but restrained reveal;
- no neon/particle/AI-gradient cliché.

## Step17I UX rules

### Homepage

- one strong material/folio card object rather than template-marketplace collage;
- obvious Create CTA;
- approved production examples only;
- when no approved templates exist, fail closed rather than leak candidate/experiment designs.

### Studio brief

Keep quick, not wizardized.

Required mental model:

- occasion;
- relationship/context;
- feeling.

Optional:

- recipient/name/detail;
- photo;
- print layout.

Photo/details remain progressive disclosure.

### Generation

Signature reveal should feel like a folio/opening/arrival, then land into the actual 3 directions. No fake delay; tune choreography from real Step18 latency.

### Results

- 3 directions only;
- no template names/catalog browsing;
- bounded customer-safe “why this fits” rationale is allowed;
- never expose raw AI internal reasoning;
- “Show me 3 new directions” remains the escape hatch.

### Finish

- design is already nearly complete;
- message edit;
- Shorter / Refine wording;
- one-step Undo after automated wording change;
- small art-directed color choice set only;
- no font/layer/position editor.

### Checkout/delivery

- one-time price;
- digital-only expectation explicit;
- final moment communicates ownership of:
  - JPG;
  - print-ready PDF;
  - recovery path.

## Accessibility/performance

- reduced-motion experience must remain premium;
- deliberate focus transfer across phase changes;
- mobile sticky actions must not obscure content;
- 44px touch targets/16px mobile inputs where applicable;
- real device/browser evidence required in Step18.

## Portfolio principle

Prefer **6–8 excellent approved launch families** over a broad uneven catalog. Human Premium/WOW/originality + Golden evidence is mandatory before `approved`.
